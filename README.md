# Desafio-Calpar

Este repositório apresenta a resolução do desafio técnico. O projeto foi desenvolvido com foco em aplicar conceitos de arquitetura de software, separação de responsabilidades e clean code.
Todas as funcionalidades e requisitos obrigatórios solicitados no escopo principal do desafio foram totalmente implementados e concluídos. Os requisitos classificados como bônus não foram escopados para esta entrega.
Para fins de organização e modularidade, a aplicação foi dividida em duas frentes de desenvolvimento: o ecossistema do backend, responsável pelas regras de negócio e estruturação da API, e o frontend, focado na interface e na experiência do usuário. Os respectivos códigos-fontes e as instruções específicas de execução para cada camada estão disponíveis em seus repositórios dedicados.
